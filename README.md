# RE4 VR – Stylish Immersion

A community add-on for **Resident Evil 4 (2023) VR**, designed to be used with **Talemann's RE4 VR mod v2.1.5**.

## Requirements

1. A working installation of Resident Evil 4 (2023) on PC.
2. **Talemann's RE4 VR mod v2.1.5**, installed and tested first.
3. **ViGEmBus**, installed.
4. **Fluffy Mod Manager**, configured for Resident Evil 4 (2023).

## Installation (once a release ZIP is available)

1. Install and verify Talemann's RE4 VR mod **v2.1.5**.
2. Install **ViGEmBus** if you have not already.
3. Download the **Stylish Immersion** Fluffy-compatible mod ZIP from this repository's **Releases** page when published.
4. Import the ZIP into **Fluffy Mod Manager** for Resident Evil 4 (2023), then enable it.
5. Launch the game using your normal working RE4 VR setup.

Do not substitute the GitHub source-code ZIP for the release mod ZIP.

## Compatibility

This add-on is intended for **Talemann RE4 VR v2.1.5**. Compatibility with other versions is not established. Keep a backup of your working configuration before installing additional mods.

## Distribution

The installable mod archive will be distributed separately through **GitHub Releases** after its contents and redistribution permissions are verified.

### Stage41a test candidate

The supplied Stage41a package includes a custom `dinput8.dll` based on Talemann 2.1.4 that **replaces** the DLL in the required 2.1.5 installation. Parity with private 2.1.5 fixes is unverified. The package's own validation notes say headset operation and the Stage41a LT prompt fix are **not yet confirmed**. Back up the working installation and treat this as experimental; do not assume it is a stable 1.0 release. No base-game files or Talemann installer are bundled here.
